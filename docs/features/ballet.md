# Ballet subject page — The Living Exhibition

Status: **Approved design direction and approved Phase 1 implementation** (2026-11-09).
Implementation scope and acceptance criteria: [docs/tasks/ballet-living-exhibition-phase-1.md](../tasks/ballet-living-exhibition-phase-1.md).

## Experience
An atmospheric, romantic, historically informed journey through Ballet. A continuous readable narrative progresses through six provisional eras, styled as rooms in a living museum. A lightweight timeline allows jumps; optional discoveries offer deeper inspection without losing reading location.

## Interaction language
- Curated discovery cards are the primary interaction.
- A few special artworks will have inspectable, accessible details after the foundational page is reviewed.
- Desktop future discovery treatment: side panel; mobile: full-screen dialog/sheet; explicit return to story, focus and scroll restoration.
- Timeline never forces scrolling or blocks uninterrupted reading.
- All motion is optional and respects reduced-motion.

## Visual personality
A restrained blush/ivory, muted rose, elegant typographic world with atmospheric imagery. Chapter environments can change subtly by era. Preserve the approved homepage visual language outside the Ballet page.

## Milestones
1. **Now:** Ballet route, theme, six-chapter editorial skeleton, responsive navigation, hero, link from homepage card, one visibly noninteractive discovery preview, screenshot review.
2. **Later:** Verified historical content, properly attributed images/sources, richer editorial modules.
3. **Later:** Reusable discovery panels, one interactive artifact, return-to-story behavior.
4. **Separate later:** Ballerina exits homepage artwork, pirouettes, transitions into page hero; skip/mobile/reduced-motion safeguards.
5. **Future platform expansion:** Cabinet of Curiosities shared across topics, explicitly not in Ballet V1.

Do not invent historical citations, mislabel AI illustrations as archival material, or add a CMS/DB in Phase 1.
