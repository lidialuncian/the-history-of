# Design system — working direction

Status: exploratory. Detailed tokens and component styles require approval.

## Shared foundation
- Editorial, cinematic, museum-like visual language.
- Strong typography, intentional whitespace, rich imagery, and clear reading hierarchy.
- Responsive layouts and accessible contrast.
- Motion should support narrative meaning, not obstruct reading.
- Keyboard access, semantic landmarks, image alternatives, and reduced-motion support are requirements.

## Subject themes
Represent subject-specific style through theme data or CSS variables, not separate duplicated applications.

Suggested theme dimensions:
- Color palette and contrast
- Display and body typography
- Image treatment and composition
- Ornament and shape language
- Motion personality
- Ambient backgrounds and transitions

## Initial subject art direction
- Ballet: soft, romantic, elegant; restrained movement.
- Tango: dramatic contrast, confident typography, dynamic movement.

## Components to explore
Global navigation, featured story, subject cards, thematic hero, timeline, story chapter, media gallery, historical figure profile, interactive map, quotation, connections between subjects.

## Not yet decided
Specific fonts, color hex values, animation library, component library, and exact page layouts. Do not treat these as fixed.
